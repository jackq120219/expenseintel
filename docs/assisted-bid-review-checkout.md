## Website audit findings (source and deployment checked; full interactive browser check not available)
- Previous PR #2 self-serve Bid Review deployed to Vercel production, free calculator is client-side and labelled honestly. Four previous GitHub checks passed. However, `bid-review/index.html` includes `<meta name="robots" content="noindex,nofollow">`, preventing normal search indexing; remove after reviewing production discovery strategy.
- The main bid comparison starts with numeric example values already filled in, even before clicking the separate fictional demo button. Remove defaults or label them clearly to prevent mistaken use of sample values for real decisions.
- The report heading says `Five-year totals? Use your selected horizon.` although visitors can choose 1–10 years. Rewrite to reflect the chosen horizon.
- Free form does not independently verify actual contractor bids or receive PDFs: keep that explanation prominent and don't promise automated comparison of real documents. `print` before generating needs manual confirmation of behavior and pagination.
- Vercel production status `READY` proves deployment, **not** that custom-domain requests or customer checkout work. The model's web fetch could not access the custom domain, and Vercel protected preview fetch redirected to SSO. Manually verify URLs and test Chrome/Safari, narrow viewport, print-to-PDF, no-JS fallback and failure/empty input states before 100-email outreach.
