03 / Cost layers

Only data that changes the expense picture.

ExpenseIntel deliberately avoids becoming another generic property-data portal. A layer belongs in the product only if it helps estimate, explain, compare, or forecast a cost.

01Core

Electricity

Provider, tariff structure, modeled consumption, seasonality and forward rate pressure.

02Core

Gas

Service, climate sensitivity, usage assumptions and future cost exposure.

03Core

Water + sewer

Local utility charges, usage assumptions and rate-change risk.

04Core

Property tax

Location-specific tax burden and scenario analysis around assessments and increases.

05Next

Insurance

Cost exposure tied to property use, location, weather and other observable risk factors.

06Next

Waste

Recurring service costs that are easy to ignore when comparing potential sites.

07Future

Infrastructure cost

Utility access and connection implications — only where they have a financial consequence.

08Future

Actual-vs-model

Upload real bills after occupancy to compare actual cost against ExpenseIntel's prior forecast.

05 / Product discipline

Built around the decision, not the dashboard.

01

Start with an address

The product must be useful before ownership. Address + property use + size create the first cost profile.

Input
02

Resolve the cost stack

Identify relevant providers, tariffs, public records and location-specific expense factors. Avoid unrelated property trivia.

Data
03

Forecast what changes

Separate known current costs from modeled future movement, uncertainty and the assumptions behind each forecast.

Forecast
04

Make alternatives comparable

Normalize to annual cost and cost per square foot so users can compare locations without rebuilding a spreadsheet.

Decision
05

Learn from actuals

Later, customer bills can calibrate the model and show whether a property is running above or below its expected cost.
